# Qualifying Round results / Результаты Отборочного этапа / Іріктеу кезеңінің нәтижелері

The Qualifying Round reports (Rules, clause 12.1) are published in this repository no later than 28 October 2026, 12:00 (Astana). The Appeals procedure is published here together with the reports.

Отчёты Отборочного этапа (п. 12.1 Положения) публикуются в этом репозитории не позднее 28 октября 2026 г., 12:00 (Астана). Порядок подачи Апелляций публикуется здесь одновременно с отчётами.

Іріктеу кезеңінің есептері (Ереженің 12.1-тармағы) осы репозиторийде 2026 жылғы 28 қазан, 12:00-ден (Астана) кешіктірілмей жарияланады. Апелляция беру тәртібі осында есептермен бір мезгілде жарияланады.
