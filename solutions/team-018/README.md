## Отчёт сборки

Построено на OpenEgiz: no — На Стенде подтвердить не удалось: `docker compose up -d --build` (из team-018-main, по README) дважды упал с «services.grafana conflicts with imported resource» (team/compose.yml переопределяет сервис grafana из подключённого через include deploy/compose/docker-compose.yml). `docker ps -a` пуст, Ditto :8080 не отвечает, поэтому ни двойников в Ditto, ни изменения данных, ни соединений MQTT наблюдать нельзя. По коду намерение правильное: team/simulator.py публикует сообщения Ditto Protocol через paho-mqtt в mosquitto, team-setup создаёт двойники через ditto-nginx, а team/dashboard.json упоминает influx 122 раза. Но условие требует, чтобы это наблюдалось на Стенде.
