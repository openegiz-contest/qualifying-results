## Отчёт сборки

Поднялось по README: нет. Построено на OpenEgiz: no — На Стенде условие подтвердить не удалось. В копии платформы openegiz/ файл openegiz/deploy/compose/ditto/40-htpasswd.sh закоммичен с режимом 100644 (в git ls-files; в шаблонном deploy/compose — 100755). Поэтому nginx пишет «Ignoring /docker-entrypoint.d/40-htpasswd.sh, not executable» и «open() /etc/nginx/nginx.htpasswd failed». Ditto на все запросы отвечает 403, в том числе на GET /api/2/search/things с паролем из .env. Init падает на создании политики, соединения MQTT не создаются, сервис ventobserve не стартует, двойников нет. По коду задумано правильно: app/platform.py публикует в MQTT telemetry/ventobserve-*, а снимок читает из Ditto; telegraf.conf опрашивает Ditto по HTTP и пишет в InfluxDB. Но в работе ничего из этого не наблюдалось.
